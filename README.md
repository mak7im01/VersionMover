# VersionMover - Перемещение номера версии

Аддон для PulseSync с гибкими настройками, который позволяет управлять отображением номера версии приложения и настраивать его внешний вид

## Описание

Аддон для тонкой настройки кнопки с номером версии (например, "5.104.2"). Позволяет управлять её вертикальным положением, внешним видом или полностью скрыть её

## Возможности

- Полное скрытие номера версии
- Выбор вертикального положения: вверху, по центру или внизу
- Изменение цвета фона кнопки
- Настройка прозрачности кнопки (10-100%)
- Все настройки применяются в реальном времени без перезапуска
